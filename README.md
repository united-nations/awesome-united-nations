## Contributing 🙌

Contributions are very welcome! This list is a work in progress and there are many UN open source projects still to be discovered.

**How to add an entry:**

1. Fork this repository
2. Add your link in the relevant section
3. Open a pull request with a brief description of what you're adding and why it belongs here

**What belongs here:**

- Open source repositories from UN system organizations or affiliated projects
- Tools, datasets, or APIs related to the UN's work
- Design systems, visualization libraries, or reusable components
- Personal or community projects in the UN open source space

If you're unsure whether something belongs, open an issue and we can discuss it.
